# Week 03 — Practical AI Tools and Engineering Exploration

## Overview

Week 03 focuses on using AI assistants for technical learning, improving prompt-writing skills, checking AI-generated information, and investigating open-source tools used in VLSI engineering.

The activities connect machine learning fundamentals with practical learning methods and semiconductor physical-design workflows.

## Activities and Assignments

| File | Description |
|---|---|
| [`ai_tools_exploration.md`](ai_tools_exploration.md) | Explores AI assistants, prompt refinement, response comparison, and verification of technical claims. |
| [`vlsi_tool_investigation.md`](vlsi_tool_investigation.md) | Investigates OpenROAD, its role in digital ASIC implementation, required inputs, outputs, and potential AI applications. |
| [`reflection.md`](reflection.md) | Records learning outcomes, challenges, future learning goals, and questions for the ML masterclass. |

## Key Topics Covered

### AI-Assisted Learning

- Understanding the possible uses of different AI assistants.
- Improving questions by adding context, constraints, and specific requirements.
- Comparing explanations from different AI tools.
- Checking technical information against reliable references.
- Using AI to support learning without depending entirely on generated answers.

### Open-Source VLSI Tools

- Investigating the purpose of OpenROAD in digital ASIC physical design.
- Understanding the stages of a typical implementation flow.
- Identifying important design files, including Verilog netlists, LEF, Liberty, and SDC.
- Exploring potential applications of machine learning in timing prediction, congestion estimation, and design optimisation.

### Responsible Use of AI

AI-generated explanations and code require appropriate verification before being used in engineering tasks. Confidential design information must also be handled according to applicable data-sharing policies.

## Learning Outcomes

This week's activities emphasise the importance of asking precise questions, checking technical claims, and understanding the limitations of AI-generated responses.

The investigation of OpenROAD also provides a foundation for connecting machine learning concepts with physical-design challenges involving timing, area, power, and routing.

## Further Learning Goals

- Continue Python practice through Harvard CS50P.
- Gain more hands-on experience with open-source VLSI tools.
- Improve the ability to interpret physical-design reports.
- Investigate how machine learning models can assist engineering analysis.
- Learn to evaluate AI-generated suggestions using evidence and practical results.

## 2. My Final Understanding

A Large Language Model (LLM) is an AI system trained on large amounts of text to learn patterns in language. When we enter a prompt, the model converts the text into smaller units called tokens. It processes the input using its learned patterns and predicts the next token. This process repeats until the response is complete.

For example, if I type "The sky is...", the model may predict "blue" because it has learned that these words commonly appear together. However, it does not always produce the correct answer because its predictions can sometimes be inaccurate.

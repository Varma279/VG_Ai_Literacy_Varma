# Mission 3: Classifying AI Applications

## 1. Classification Table

| Application              | Classification                    | Reason                                                                         |
| ------------------------ | --------------------------------- | ------------------------------------------------------------------------------ |
| Calculator               | Rule-based / Traditional Software | It follows predefined mathematical rules and formulas to calculate results.    |
| Temperature Warning Rule | Rule-based / Traditional Software | It generates a warning when the temperature crosses a predefined limit.        |
| Spam Filter              | ML-based AI                       | It learns patterns from emails to identify unwanted or spam messages.          |
| Document Summariser      | Generative AI                     | It generates a shorter version of a document while preserving its main points. |
| Traffic ETA Prediction   | ML-based AI                       | It uses traffic data and learned patterns to predict travel time.              |

## 2. One Easy Classification

The calculator was easy to classify because it follows predefined mathematical rules to produce answers. It does not need to learn patterns from data.

## 3. One Difficult Classification

The spam filter was difficult to classify because some spam filters use machine learning to identify spam, while others use predefined rules. Therefore, its classification depends on how it is designed.

## 4. My Own Example

**Example: AI Story Generator**

An AI story generator is an example of Generative AI because it creates a new story based on the user's prompt instead of simply selecting a predefined answer.

## 5. Anchor Question

**If the rules are written explicitly, is that the same as a model learning a pattern?**

No. Explicit rules are written by a programmer, whereas a machine learning model learns patterns from data during training. Both can make decisions, but they use different approaches.

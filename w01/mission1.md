# Mission 1: Find AI Around Me

## 2. Evidence that AI is involved

I selected YouTube recommendations to check whether AI is actually used.

According to the official YouTube Help page, YouTube uses information such as watch history, search history, subscriptions and likes to recommend videos. Its recommendation system learns from viewing habits and tries to suggest videos that a user may like.

**Source:** [How YouTube Recommendations Work — Official YouTube Help](https://support.google.com/youtube/answer/16089387?hl=en)

This confirms that AI and machine learning are involved in YouTube's recommendation system.

## 3. Could a simple rule-based program do something similar?

Yes, a simple rule-based program could recommend videos based on fixed rules. For example, if a person watches a lot of cricket videos, the program could show more cricket videos.

However, a rule-based program mainly follows the rules written by the programmer. A machine learning system can learn patterns from user activity and make more personalised recommendations.

## Conclusion

I noticed that I use different intelligent features in my daily life. After checking the official YouTube source, I learned that its recommendation system uses machine learning. I also understood that some similar tasks can be done using simple rules, but machine learning can find more complex patterns in user behaviour.

# Week 01: Reflection

### 1. What is the most useful thing I learned this week?

The most useful thing I learned is that AI can help me understand concepts and solve problems, but I should not blindly trust every answer. I must check important information using reliable sources.

### 2. What did I initially misunderstand?

Initially, I thought that every system that behaves intelligently must use AI. I learned that ordinary programs can also perform tasks by following fixed rules, while machine-learning systems can learn patterns from data.

### 3. What did AI help me do?

AI helped me understand AI concepts in simple words, learn how Large Language Models work, organize my assignment, and understand basic Python programming with examples.

### 4. Where did I need to verify or correct AI?

I learned that AI-generated answers can be incomplete or incorrect even when they sound confident. For example, the statement that all birds can fly is incorrect because ostriches and penguins cannot fly. This taught me to check important claims against reliable references.

### 5. What is one question I want answered on Saturday?

I would like to understand how AI can be used in real engineering projects and how I can use Python to automate simple engineering tasks in the future.

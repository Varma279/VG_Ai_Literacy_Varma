# Week 04 — Deep Learning Fundamentals

## Overview

This week focuses on understanding the fundamentals of deep learning, how neural networks process information, how they learn from data, and how they can be applied to engineering problems.

The activities combine conceptual learning, visual experimentation and an engineering case study related to VLSI Physical Design.

## Learning Objectives

By completing this week, I aimed to understand:

* [x] How raw data is prepared for deep learning.
* [x] The relationship between AI, ML and deep learning.
* [x] The basic architecture of a neural network.
* [x] The purpose of neurons, weights, biases and activation functions.
* [x] How forward propagation and backpropagation work.
* [x] The difference between training and inference.
* [x] How network complexity affects classification.
* [x] How deep learning could support VLSI Physical Design.

## Practical Experiment

**Tool:** TensorFlow Neural Network Playground

The experiment explored:

* Different numbers of hidden layers and neurons.
* The effect of additional input features.
* Changes in decision boundaries.
* The relationship between network complexity and classification patterns.

## Engineering Application

**Case Study:** Deep Learning for Routing Congestion Prediction in VLSI Physical Design.

The case study explores how a neural network could use placement and routing-related information to identify potential congestion hotspots before detailed routing.

This is a proposed application supported by published research, not an implementation completed as part of this assignment.

## Key Takeaways

1. Data quality and preparation strongly influence model learning.
2. Neural networks learn patterns through interconnected computational units.
3. Backpropagation helps update network parameters based on prediction errors.
4. Increasing network complexity does not always improve performance.
5. Unseen data is important for evaluating generalisation.
6. Deep learning can support engineering decisions, but human verification remains necessary.

1.  Build the AI and ML Landscape

## 1. Simple explanation
- **Artificial intelligence (AI):** A broad area of computing that aims to make systems perform tasks that seem to need human intelligence.
- **Rule-based programming:** A person writes the rules directly. The program follows those rules.
- **Machine learning (ML):** A system uses examples or data to learn patterns instead of having every decision written as a fixed rule.
- **Deep learning:** A type of ML that uses neural networks with many layers.
- **Generative AI:** AI that creates new content, such as text, pictures, or code.
- **Large language model (LLM):** A model trained to process and generate language. Many modern LLMs use transformer architectures.

## 3. Five distinctions

| Comparison | Simple difference | Basic example |
|---|---|---|
| AI vs automation | Automation follows a process; AI may handle tasks requiring pattern recognition or generation. Automation is not automatically AI. | A timer turns a lamp on at 7 PM: automation. |
| Rule-based vs ML | Rules are written by a person; ML learns patterns from examples. | `if temperature > 30` vs a model estimating tomorrow's temperature from past data. |
| AI vs ML | AI is the wider field; ML is one approach within it. | A rule-based expert system can be AI without ML. |
| ML vs deep learning | Deep learning is one type of ML using multi-layer neural networks. | A simple decision tree vs a deep image-recognition network. |
| Generative AI vs LLM | Generative AI is a broad group; an LLM is a model focused on language. | An image generator vs a chatbot that writes text. |

## 4. Examples 

| Example | Category | Reason |
|---|---|---|
| Calculator adds 5 + 3 | Conventional rule-based program | It follows exact programmed arithmetic rules. |
| Email spam filter trained on labelled emails | Machine learning | It learns patterns from examples marked spam or not spam. |
| Chatbot writes a birthday message | Generative AI, often using an LLM | It generates new text in response to a prompt. |

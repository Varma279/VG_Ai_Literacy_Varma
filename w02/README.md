# Week 02 — Machine Learning Foundations

## Overview

This week focused on the fundamentals of machine learning, including data preparation, learning methods, model evaluation, and practical applications in engineering.

* [x] **Mission 2 — Understand Data:** Learned about datasets, features, targets, data types, and the importance of data quality.

## Key Learnings

1. Data quality plays an important role in building reliable ML models.
2. Different ML approaches are suitable for different learning situations.
3. Classification predicts categories, while regression estimates numerical values.
4. Training teaches a model from data, whereas inference uses the trained model to produce predictions.
5. Model performance must be checked using appropriate evaluation metrics and unseen data.
6. Traditional programming can be more suitable than ML for problems with clearly defined rules.
7. ML predictions in semiconductor engineering require proper validation and engineer review.

## Practical Applications

This week's concepts were connected to engineering problems such as:

* Predicting chip power consumption.
* Identifying possible timing failures.
* Detecting unusual sensor readings.
* Evaluating the reliability of model predictions.

These examples illustrate potential applications and do not imply that the proposed systems have been deployed in industry.
